# Рантаймы для игровых движков

Анимация из редактора уходит в движок файлом `.bytefall`: «Экспорт» (`Ctrl+E`) → «Для движка».
В файле атлас символов и для каждого кадра — список символов с положением, поворотом, масштабом,
цветом символа и цветом фона. Движок рисует кадр одним мешем из квадов, поэтому картинка чёткая
при любом масштабе, а цвет всей анимации меняется в самом движке.

Кадры запекаются: огонь, деформеры, риг и ключи уже посчитаны редактором, движку остаётся
показывать кадры по очереди. Материалы объектов (свечение, контур, блик, дизеринг) и
постэффекты в файл пока не попадают.

## Godot 4

Проверено на Godot 4.7.

1. Скопируйте папку `godot/addons/bytefall` в `addons/` своего проекта.
2. «Проект → Настройки проекта → Плагины» — включите Bytefall.
3. Положите файл `.bytefall` в проект: он импортируется как ресурс `BytefallAnimation`.
4. Добавьте в сцену узел `BytefallPlayer` и перетащите ресурс в поле `Animation`.

Настройки узла: `cell_size` — размер ячейки в пикселях, `centered` — центр холста в начале
координат узла, `draw_background` — рисовать цвет холста, `autoplay`, `loop`, `speed_scale`.
Из кода: `play()`, `stop()`, `seek(мс)`, сигнал `finished` у анимации без петли. Цвет — через
`modulate`, как у любого узла 2D.

## Unity

Проверено на Unity 6 во встроенном конвейере рендера и в URP, с обычным и 2D-рендерером, в
гамма- и в линейном цвете.

1. Window → Package Manager → «+» → Add package from disk → выберите
   `unity/com.bytefall.runtime/package.json`. Или из git:
   `https://github.com/T4rnum/bytefall-editor.git?path=runtimes/unity/com.bytefall.runtime`.
2. Положите файл `.bytefall` в `Assets`: он импортируется как `BytefallAnimation` с атласом и
   материалом внутри.
3. Добавьте объекту компонент Bytefall Player и перетащите ассет в поле `Animation`.

Настройки компонента: `cellSize` — размер ячейки в единицах мира (0.16 — 16 пикселей при 100
пикселях на единицу, как у спрайтов по умолчанию), `centered`, `drawBackground`, `tint`,
`sortingOrder`, `playOnAwake`, `loop`, `speed`. Из кода: `Play()`, `Pause()`, `Stop()`,
`Seek(мс)`, событие `Finished`. После смены полей из кода — `Refresh()`.

Анимацию можно загрузить и в игре, без импорта: `BytefallAnimation.FromBytes(bytes, out error)`,
например из StreamingAssets.

## Формат

Раскладка файла описана в [`src/core/bytefall.ts`](../src/core/bytefall.ts): заголовок JSON,
атлас PNG и по 32 байта на символ. Рантайм для другого движка пишется по этому описанию; нужен
один материал «текстура × цвет вершины».
