# Bytefall Editor

Редактор символьной графики: холст из ячеек, в каждой — глиф шрифта плюс цвет символа и цвет фона.
Смесь растрового редактора и 3D-пакета, но вместо пикселей и полигонов — символы.

## Что это

Инструмент для художников, которые рисуют символами: ASCII-арт, текстовые игры, терминальная
эстетика. От обычного ASCII-редактора отличается тем, что символ здесь — не буква в текстовом файле,
а полноценный графический объект: у него есть цвет, фон, слой, эффекты, а в перспективе — поворот,
масштаб, риг и освещение.

Конечная цель — чтобы результат можно было импортировать в игровой движок и делать на этой графике
игру.

## Что уже работает

- **Холст.** Сетка ячеек до 1024×1024, шрифт Press Start 2P, зум колесом вокруг курсора,
  панорамирование, подгонка под окно. Размер меняется в диалоге `Ctrl+Alt+C`: якорь из девяти
  положений решает, какой край обрезать, предпросмотр показывает это заранее.
- **Инструменты.** Карандаш, ластик, линия, прямоугольник, эллипс, заливка, пипетка, текст.
  Живое превью штриха до отпускания кнопки.
- **Выделение.** Рамка, лассо и волшебная палочка — произвольной формы, а не только прямоугольник.
  `Shift` добавляет к выделению, `Alt` вычитает, перетаскивание внутри переносит ячейки. Пока
  выделение есть, инструменты меняют только его ячейки; `Escape` снимает его.
- **Две кисти.** У левой и правой кнопки мыши свой символ и свои цвета: `B` переключает, какую
  правят панели, `Shift+X` меняет их местами. Пустая кисть без фона стирает — такой правая и
  заведена по умолчанию.
- **Слои.** Добавление, дубликат, порядок, видимость, блокировка, непрозрачность.
- **Объекты.** Группировка выделения в именованный объект, перетаскивание целиком, инспектор
  свойств, впечатывание обратно в растр.
- **Анимация.** Покадровая: кадры с индивидуальной длительностью, onion skin, проигрывание.
- **Эффекты.** Неразрушающие эффекты уровня ячеек на слое: пульс, волна, мерцание, прокрутка,
  перебор символов, огонь. Детерминированы временем, поэтому экспорт совпадает с экраном.
- **Пост-обработка.** Свечение, строки развёртки, виньетка. Применяются и к экспорту.
- **Файлы.** Формат `.bp.json` со схемой, версионированием и миграциями. Экспорт PNG, TXT, GIF
  и спрайтшита.
- **История.** Undo/redo, где стоимость записи пропорциональна размеру штриха, а не размеру холста.
- **Автосохранение.** Несохранённая работа копируется в хранилище браузера, и после аварийного
  закрытия вкладки редактор предлагает её вернуть. Несколько открытых вкладок друг другу не мешают.

Чего ещё нет: ключевой анимации, трансформаций объектов, 3D, импорта изображений. План — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Быстрый старт

Нужен **Node 24** (версия зафиксирована в `.nvmrc`). Минимум — 22.12, на Node 20 сборщик не запустится.

```bash
npm ci
npm run dev
```

Откроется на `http://127.0.0.1:5173`.

Одна команда, которая проверяет всё, что проверяет CI:

```bash
npm run check
```

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с горячей перезагрузкой |
| `npm run build` | typecheck + production-сборка |
| `npm test` | юнит-тесты ядра |
| `npm run coverage` | покрытие `src/core` |
| `npm run bench` | бенчмарки ядра, см. [docs/BENCHMARKS.md](docs/BENCHMARKS.md) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint |
| `npm run format` | Prettier, запись |
| `npm run check` | всё вышеперечисленное разом |

## Архитектура кратко

```
Document ──composite()──▶ CellBuffer ──GridMesh.update()──▶ GPU (один draw call)
   ▲                          ▲
   │ commit(edits)            │ preview(edits)
 инструменты ◀── события мыши и клавиатуры ── Viewport
```

Три слоя с жёсткими границами:

- **`src/core`** — чистые функции над неизменяемыми данными. Ни DOM, ни React, ни Three.js, ни
  Zustand. Вся логика документа, сетки, истории, анимации, эффектов и формата файла живёт здесь и
  покрыта тестами (~98% строк).
- **`src/render`** — только Three.js. Получает готовый кадр ячеек и рисует его. Ничего не знает
  о состоянии приложения.
- **`src/app`** — React и Zustand. Панели, инструменты, файловые операции.

Подробно: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — как устроено сейчас,
[docs/DESIGN.md](docs/DESIGN.md) — куда это развивается и почему именно так,
[docs/BENCHMARKS.md](docs/BENCHMARKS.md) — база производительности.

Ядро покрыто тестами примерно на 98%, включая замороженные фикстуры всех версий формата файла и
золотые снимки композитора.

## Стек

TypeScript 5.9 strict · React 19 · Zustand 5 · Three.js r186 (WebGL2) · zod 4 · Vite 8 · Vitest 5 ·
ESLint 10 · Node 24.

Один пакет без воркспейсов, относительные импорты, без алиасов. Выбор стека и отвергнутые
альтернативы разобраны в [docs/DESIGN.md](docs/DESIGN.md#стек).

## Происхождение

Проект вырос из двух прототипов, оба лежат рядом в архиве:

- **Bytefall** — первый прототип. Отсюда взяты идеи: чанковый инстансированный рендер, MSDF-атлас,
  рисование на ЛКМ и ПКМ разными символами, поля-«драг-числа» в стиле Blender.
- **BlendPhoto** — второй заход с чистым ядром и тестами. Отсюда взят весь код этого репозитория.
