# Дорожная карта

Правило: каждый слой заканчивается работающей вещью, которой можно пользоваться. Следующий слой не
начинается, пока предыдущий не закоммичен с тестами и `npm run check` не зелёный.

Слои определены через «что можно делать в конце», а не через календарь. Решения, на которых они
стоят, — в [DESIGN.md](DESIGN.md).

---

## Слой 2. Рендер: тайлы и грязные области

- [ ] Тайлы 32×32 с флагом «грязный».

- [ ] Кэш тайлов в композиторе.

## Слой 4. Трансформации объектов

Первое появление инстансного пути рендера, см.
[DESIGN.md, раздел 2](DESIGN.md#2-главный-инвариант-где-живут-дробные-координаты).

- [ ] `Transform2D` на объекте: поворот, масштаб, pivot, ограниченный визуальный сдвиг.
- [ ] `InstanceMesh` рядом с `GridMesh`, отдельный проход для инстансных слоёв.
- [ ] Гизмо трансформации во вьюпорте.
- [ ] `overrides`: поворот и размер отдельного выбранного символа или группы символов.
- [ ] `rasterize()` — общая функция для экспорта в текст и команды «впечатать в слой».
- [ ] Иерархия: `parentId`, группировка объектов, наследование трансформа.
- [ ] Формат файла: новая версия с миграцией.

**Готово, когда:** группу символов можно повернуть и отмасштабировать, отдельному символу можно
задать свой поворот и размер, экспорт в текст по-прежнему однозначен.

## Сквозное через все слои

- Золотые тесты «экран равен экспорту» на каждую новую возможность рендера.
- Бенчмарки в репозитории, а не в устных оценках.
- Миграция схемы и фикстура старой версии на каждое изменение формата.
- Каждая фича получает место в интерфейсе и горячую клавишу до того, как считается готовой.
