# Дорожная карта

Правило: каждый слой заканчивается работающей вещью, которой можно пользоваться. Следующий слой не
начинается, пока предыдущий не закоммичен с тестами и `npm run check` не зелёный.

Слои определены через «что можно делать в конце», а не через календарь. Решения, на которых они
стоят, — в [DESIGN.md](DESIGN.md).

---

несуществующую функциональность.

- [x] Индекс ячеек по тайлам и частичная пересборка кадра: мазок пересобирает один-два тайла
      вместо всего холста. Равенство с полной пересборкой закреплено 12 тестами.
- [ ] Грязные тайлы для коммита и структурных правок, а не только для превью штриха.
- [x] Кэш эффектов по подписи времени и тик, не меняющий картинку, не доходит до композитора.
- [ ] Culling тайлов по вьюпорту.
- [ ] Восстановление после потери WebGL-контекста.
- [ ] Браузерная гарнитура: пиксельные снимки PNG и замер FPS на production-сборке.

**Готово, когда:** бенчмарк показывает, что одиночный мазок не трогает весь холст, 256×144 держит
60 FPS при рисовании, 512×288 — не меньше 30, повторный resize не растит GPU-память.
Числа сравниваются с базой в [BENCHMARKS.md](BENCHMARKS.md).

## Слой 12. Настраиваемое рабочее место

Ориентир — VS Code: панель можно перетащить в другую зону, вынести в отдельное окно, скрыть.
Это не косметика: у рисования, анимации и работы с 3D разные наборы нужных панелей, и раскладка
под одну задачу мешает другой.

- [ ] Панель как самостоятельная сущность с идентификатором, а не жёстко вписанная в сайдбар.
- [ ] Зоны размещения: левая и правая колонки, нижняя полоса, вкладки внутри зоны.
- [ ] Перетаскивание панели между зонами с подсветкой места вставки.
- [ ] Сохранение раскладки и готовые наборы под задачу: рисование, анимация, 3D.
- [ ] Отдельное окно для панели.
- [ ] Редактор тем поверх токенов из `styles/tokens.css`.

**Готово, когда:** пользователь собирает рабочее место под себя, раскладка переживает
перезагрузку и переключается между наборами одним действием.

Отдельные предпосылки уже заложены: панели сворачиваются и запоминают состояние, ширина сайдбара
тянется, всё оформление идёт через токены. Полноценный докинг требует, чтобы панели перестали быть
жёстко перечисленными в `App.tsx`, — это и есть основная работа слоя.

## Сквозное через все слои

- Золотые тесты «экран равен экспорту» на каждую новую возможность рендера.
- Бенчмарки в репозитории, а не в устных оценках.
- Миграция схемы и фикстура старой версии на каждое изменение формата.
- Каждая фича получает место в интерфейсе и горячую клавишу до того, как считается готовой.
